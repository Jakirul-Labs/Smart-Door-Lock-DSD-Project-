# Smart Door Lock Access Control System ##

## Project Overview:
This project implements a **Smart Door Lock Access Control System** using **Arduino IDE** and an **RFID card reader**.  
It allows **secure access to a door** only to authorized RFID cards.

--This system is ideal for **home automation, office security, and educational purposes**.  

> **Note:** Project includes **component images, circuit diagrams**.(**Follow Project_Presentation pdf**).
> All media files are organized inside images/ and videos/ folders.
> **"To watch the video, you need to download it because GitHub does not play videos directly."**

## Features
- RFID card-based authentication  
- Arduino reads authorized cards from EEPROM  
- Solenoid/electric strike controlled by Arduino  
- Status LEDs indicate lock/unlock and invalid access  
- Optional buzzer/alarm for unauthorized access  
- Lockout after repeated invalid attempts  
- Modular and expandable design
